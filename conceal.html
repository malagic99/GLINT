Concealer

Hides an encrypted message or file inside a photograph. The picture still looks like the picture, and the payload survives being re-saved as JPEG.

Compression is fine; geometry is fatal. Re-saving, re-compressing and emailing the file all work. Resizing, cropping or rotating destroy the payload — so send the file itself, not a photo through a service that shrinks it.
