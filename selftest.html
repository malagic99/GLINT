Security key dry run

Exercises the whole scheme end to end with a throwaway payload: enrol the key, seal a file, then open it three separate ways. Run this before trusting anything you care about — an untested recovery path is the same as no recovery path.

You will be asked to touch the key several times: once to enrol, once to seal, and once to open. That is expected — each touch is a separate PRF evaluation, and none of them can be skipped or replayed.

Requires HTTPS or localhost, and a key with FIDO2 hmac-secret (YubiKey 5 series and later).
